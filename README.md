# Motion Dither

Интерактивный сайт, который накладывает на изображение анимированный дизеринг (motion dither). Рендеринг на WebGL, без зависимостей и сборки.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

Сайт можно разместить на GitHub Pages / Netlify / Vercel как обычную статику.

## Возможности

- **Изображение:** загрузка файла, drag & drop, вставка из буфера (Ctrl+V), случайное фото (picsum.photos) или встроенная демо-сцена.
- **Алгоритмы:** Bayer 2×2 / 4×4 / 8×8 / 16×16, градиентный шум (IGN), белый шум, полутон, линии, порог.
- **Цвет:** палитры (Ч/Б, Game Boy, CGA, PICO-8 и др.), редактор своей палитры до 8 цветов, режим RGB с уровнями на канал, инверсия.
- **Тон:** яркость, контраст, гамма.
- **Движение:** скорость, ограничение fps, дрейф паттерна по X/Y, временное мерцание, волна (амплитуда/частота/скорость), пульсация яркости, глитч.
- **Курсор:** линза и рябь вокруг указателя (сила, радиус).
- **Экспорт:** PNG, запись видео WebM, ссылка с настройками.
- Пресеты, случайные настройки, автосохранение в `localStorage`.

Двойной клик по названию ползунка возвращает значение по умолчанию.

**Клавиши:** Пробел — пауза, S — PNG, R — случайно, H — скрыть панель.
